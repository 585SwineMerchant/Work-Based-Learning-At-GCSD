# Wednesday Presentation Table Setup

## Screen Assignment

- ViewSonic: open `/pages/presentation.html` full screen. Transition from this display into the submitted Module 5 Board presentation deck for the 15-minute pitch.
- Laptop: open `/pages/attention.html` full screen as the silent looping attention getter.
- iPad: open `/pages/support.html` landscape for employer/pathway supporting information, or use `/pages/forms-resources.html` as a handout gallery.

## Physical Table Layout

Place the table covering first, then set printed literature in five clear groups: What Is Culinary Work-Based Learning, Student and Family Pathway Guide, Employer Partnership Opportunities, Program Outcomes and Annual Plan, and QR information cards. Put the QR code at the front-right corner and another copy near the ViewSonic. Keep the laptop angled toward the camera and the iPad beside the handouts.

## Launch Order

1. Connect power for ViewSonic, laptop, and iPad.
2. Open the local or live website on all devices.
3. ViewSonic: load `/pages/presentation.html`, set browser zoom to 100%, enter full screen.
4. Laptop: load `/pages/attention.html`, enter full screen, confirm it loops.
5. iPad: load `/pages/support.html`, rotate landscape, hide browser chrome if possible.
6. Open the submitted Module 5 deck in a separate app or tab before recording.

## ViewSonic and Camera Check

Use 16:9 display resolution when available. Confirm the entire digital board fits without scrolling, text is readable from several feet away, and the QR code is visible. Frame the shot so the table, display, laptop, iPad, and printed literature are all readable without glare.

## Transition to Board Pitch

Start the recording on the table display. Briefly identify the four Module 2 table components: digital display board, table covering/program identity, supplementary literature, and attention getter. Then switch the ViewSonic to the submitted Module 5 Board presentation and deliver the pitch without changing the slide sequence or script substance.

## Offline Fallback

Before filming, open each route once while online: `/`, `/pages/presentation.html`, `/pages/attention.html`, `/pages/support.html`, and `/pages/forms-resources.html`. If internet is unreliable, run a local preview from the repository with `python -m http.server 8080` and use `http://localhost:8080/` on the laptop. For iPad fallback, keep printed handouts and QR cards visible even if the support screen cannot load.

## Rehearsal Checklist

- Printed handouts are sorted and not clipped.
- QR code scans to the live site.
- ViewSonic display is full screen and readable.
- Attention loop advances without sound.
- iPad support screen is landscape and awake.
- Notifications are silenced on all devices.
- Batteries and chargers are ready.
- Room lights avoid glare.
- Audio records clearly for the 15-minute pitch.

## Final Five-Minute Check

Scan the QR code, start the attention loop, check ViewSonic framing, open the Module 5 deck, silence notifications, confirm microphone input, and make sure the first printed handout visible to the camera is the What Is Culinary Work-Based Learning overview.
